# Worldmaptools · Atlas Studio 世界地圖工作室

**版本：v1.0.1** · [English documentation](docs/README.en.md) · [版本紀錄](CHANGELOG.md) · [資料授權政策](docs/DATA_LICENSES.md)

可縮放的互動世界地圖，用顏色和圖示記錄地區，並逐級拆分行政區獨立編輯。

## 快速啟動

安裝 Node.js 20 或更新版本，下載本專案後執行：

```sh
npm start
```

開啟 http://127.0.0.1:4173 。不需要安裝 npm 套件，也不需要編譯。請透過 HTTP 開啟，勿直接雙擊 HTML 檔案。可用 `PORT` 環境變數調整連接埠。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| 著色模式：單擊區域 | 直接套用選取顏色 |
| 圖示模式：單擊區域 | 放置圖示；首次使用時輸入說明 |
| 清除模式：單擊區域 | 清除該區域標記 |
| 雙擊區域 | 拆分至下一層行政區 |
| 合併未標記區域 | 將空白部分合回上一層，保留已著色／有圖示的部分 |
| 滾輪、＋／−、拖曳 | 縮放與移動地圖 |
| 圖例項目 | 選用相同顏色／圖示繼續編輯 |
| 圖例 ✎／× | 修改說明／刪除圖例並清除所有同款標記 |
| 復原 | 還原本次工作階段的最近操作，最多 25 筆 |
| 匯出／匯入 | 下載或載入地圖 JSON 存檔 |
| 右上角語言選單 | 切換繁體中文／英文，記住偏好 |

鍵盤可聚焦區域後按 Enter 套用標記，Shift+Enter 拆分。單擊約有 260 毫秒的判定延遲，以區分雙擊。

左上角顯示目前可編輯、已著色與未著色區域數。**未著色少於 10 個時**列出名稱，點擊即可縮放定位；只有圖示、沒有填色的區域仍算未著色。

## 行政區與資料範圍

- 預設為國家；依資料提供的大區、省、州、縣市層級拆分，最多 ADM5。
- 德國依序為邦、大區、獨立市／縣。慕尼黑市與慕尼黑縣是不同區域。
- 台灣以縣市為最小層級；中國與台灣使用獨立的編輯根節點。中國圖層會排除台灣及其縣市邊界，包括金門、馬祖，避免覆蓋與跨區繼承。
- 已補正來源檔中法國、挪威缺失的國家代碼，並保留舊存檔 ID。
- 法國目前的來源提供 13 個本土大區。各國資料的涵蓋範圍、年代與層級不一致，不能保證全球所有縣市都有資料。
- 國家名稱依語系切換；台灣縣市有繁中名稱。其他行政區保留來源地名，自訂圖例說明不翻譯。

邊界只供視覺化使用。上下層資料缺少統一父區識別碼，因此部分隸屬關係以幾何代表點推算；不同年份的邊界可能無法完全對齊。縣市停止層級依行政區類型判斷，並非完整的全球行政區分類系統。

## 儲存、隱私與部署

地圖資料和語言偏好保存在瀏覽器 `localStorage`，不同網域／瀏覽器不會自動同步。請定期匯出 JSON 備份。復原歷史僅保留在目前工作階段。匯入沿用 `version: 1` 存檔格式；軟體版本 `v1.0.0` 與存檔格式版本不同。

本專案沒有後端或帳號系統。行政區按需從 geoBoundaries／GitHub 下載，因此仍需要網路；Leaflet 與幾何程式庫已隨網站附帶，字型改用系統字型。任何靜態網站主機都可直接發布 `dist/`，實際權限由擁有者設定。此 GitHub 版本不含原 Sites 的私人部署設定，也不含使用者的地圖存檔。

左側「資料來源與授權」可查看原始提供者、授權、資料版本及更新日期，並下載目前的邊界資料、來源清單與機器可讀修改方法。這份邊界下載不包含個人顏色、圖示或自訂圖例說明。未知或不支援的授權圖層會暫停載入；詳見 [資料授權政策](docs/DATA_LICENSES.md) 及網站內的 `sources.html`。

## 測試與效能

```sh
npm test
```

測試涵蓋國家代碼、台灣隔離、圖例、部分合併、語系、統計和圖層更新。`tests/` 中的 GeoJSON 是公開邊界回歸測試資料。

合併後的剩餘範圍依幾何內容快取；單純上色只更新 Leaflet 樣式，不重建所有圖層。效能比較需自備地圖存檔與俄羅斯 ADM1 GeoJSON：

```sh
node tests/performance.cjs /path/to/map.json /path/to/russia-adm1.geojson
```

## 專案結構與第三方資料

`dist/` 為可部署網站；`scripts/` 為本地伺服器與測試入口；`tests/` 為回歸測試與公開資料；`VERSION`、`package.json` 和 Git 標籤記錄軟體版本。

- [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) 世界國界，透過 [datasets/geo-countries](https://github.com/datasets/geo-countries) 取得。
- [geoBoundaries gbOpen](https://www.geoboundaries.org/api.html) 行政區；各資料來源、年份與授權可能不同。台灣資料中繼資訊見 `dist/taiwan-source.json`。
- [Leaflet 1.9.4](https://leafletjs.com/)（BSD-2-Clause，隨專案附帶）、[Turf 7.2.0](https://turfjs.org/) 的所需子集（各模組及依賴保留各自授權）。完整 runtime 聲明、版本與指紋在 `dist/licenses/`；可用 `tools/geometry-bundle/` 的固定依賴與建置腳本重建。

本次未替專案自有程式碼指定開源授權；是否授權他人使用與散布，請由擁有者決定。
